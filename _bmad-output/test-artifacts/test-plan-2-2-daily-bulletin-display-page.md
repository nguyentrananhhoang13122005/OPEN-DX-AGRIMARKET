### TC-2.2-02: BulletinView Markdown Rendering (Unit)

**Type:** Unit
**Tool:** Jest + RTL
**Priority:** P0

```typescript
// __tests__/presentation/components/features/bulletin/BulletinView.test.tsx
import { render, screen } from '@testing-library/react'
import { BulletinView } from '@/components/features/bulletin/BulletinView'

describe('BulletinView', () => {
  const mockBulletin = {
    id: '1',
    commodity: 'Gạo',
    bulletin_vi: '## Tiêu đề\nGiá lúa **tăng** [1].',
    sources_json: [{ source: 'USDA', date: '2026-08-01' }],
    model_used: 'llama3',
    is_latest: true,
    created_at: new Date()
  }

  it('renders markdown to HTML correctly', () => {
    render(<BulletinView bulletin={mockBulletin} />)
    
    expect(screen.getByRole('heading', { level: 2 })).toHaveTextContent('Tiêu đề')
    expect(screen.getByText('tăng')).toHaveStyle('font-weight: bold') // Or check tagName === 'STRONG'
  })

  it('renders empty state if no bulletin provided', () => {
    render(<BulletinView bulletin={null} />)
    expect(screen.getByText(/Không có bản tin/i)).toBeInTheDocument()
  })
})
```

**Pass Criteria:** Markdown is correctly parsed into native HTML elements.
**Fail Criteria:** Renders raw markdown string or crashes.
