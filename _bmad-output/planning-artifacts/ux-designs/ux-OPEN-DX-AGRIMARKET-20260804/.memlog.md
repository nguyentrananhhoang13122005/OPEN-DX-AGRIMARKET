## Log

### 2026-08-04 — event
Spines finalized. DESIGN.md and EXPERIENCE.md created from PRD + Architecture sources.

### 2026-08-04 — decision
Primary brand color: Agricultural green #16A34A. Rationale: directly tied to crop health semantics; not generic teal/blue typical of SaaS. Aligned with ARCHITECTURE-SPINE AD-6 color tokens.

### 2026-08-04 — decision
Harvest orange #EA580C chosen as accent (vs amber or red). Rationale: warm and grounded; used exclusively for high-stakes irreversible actions (Approve Harvest, Export QR). Does not trigger alarm-like response of red, nor does it blend with tending-status amber.

### 2026-08-04 — decision
Four parcel status colors formed as a closed semantic set: Green/Amber/Orange/Blue. These colors are NOT available for any other semantic use in the product. This prevents color-meaning drift as the product scales.

### 2026-08-04 — decision
Inter typeface chosen over Nunito/Roboto. Rationale: excellent Vietnamese diacritic rendering at small mobile sizes; open-source (OFL); workhorse-class legibility over display expressiveness — matches the operational, not consumer, posture.

### 2026-08-04 — decision
Farmer role uses body-large (17px) via [data-role="farmer"] on layout root, not separate components. Rationale: keeps component surface small, avoids per-component farmer variants. Architecture already provides the data-role pattern via role-based layouts.

### 2026-08-04 — decision
TTS button hidden (not disabled) when Piper unavailable. Rationale: a disabled button implies something the user can't do — they'd try to debug why. Hidden means the feature simply doesn't exist at this moment. Reduces friction and confusion for low-tech users.

### 2026-08-04 — decision
Navigation strategy: Manager/Officer use sidebar on desktop + bottom nav on mobile. Farmer uses bottom nav only (3 items). Rationale: Farmer is single-surface mobile; sidebar would waste vertical space and add cognitive overhead for a user population that expects mobile-first patterns.

### 2026-08-04 — decision
AI citation microcopy format: "(Nguồn: [SOURCE], [DD/MM/YYYY])". Applied to all AI-generated content blocks (Bulletin, Chatbot, Disease diagnosis). This is an invariant — not configurable per screen.

### 2026-08-04 — decision
Confidence percentage shown as plain text (not color-coded traffic light) for disease diagnosis. Rationale: color-coding confidence would imply clinical reliability of the AI score, which is misleading. Text + threshold warning at <60% is more honest.

### 2026-08-04 — assumption
Piper TTS HTTP server available in Docker Compose at internal port 5500. If Piper exposes a streaming endpoint, TTS button streaming can be implemented; if batch-only, pre-generate on demand (MVP) or nightly (post-30/8).

### 2026-08-04 — assumption
SSE (Server-Sent Events) sufficient for notification bell real-time count. WebSocket deferred per PRD scope.

### 2026-08-04 — assumption
No inter-role navigation requirements. Notifications deep-link within the receiving role's own IA (e.g., Manager notification → Manager lot detail page, not Officer lot detail).
