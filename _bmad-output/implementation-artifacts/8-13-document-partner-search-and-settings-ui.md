# Story 8.13: Documents, Partners, Search & User Settings Completion UI

Status: ready-for-dev
Epic: 8 — FE Prototype Reconstruction
Phase: FE prototype

## Story

As a Manager, Officer or Farmer, I want complete document, partner, search and account-setting surfaces, so that the prototype covers the operational navigation users expect.

## Acceptance Criteria

1. PARA supports folder creation, move, tags, search, preview, privacy state, upload progress and unavailable/retry states.
2. Certificates support upload, PDF preview, replace/delete, expiry indicator and selection state for lot review.
3. Partner directory/detail supports contact actions, edit/delete confirmation and verified/unverified state; map and list remain consistent.
4. Global search returns grouped results for households, parcels, journals, lots, documents and partners with filters and empty/error states.
5. Personal settings support avatar, phone/language/notification preferences with unsaved-change and save/error states.
6. This story uses mock fixtures only; MinIO, partner, profile and search APIs are integration dependencies.

Dependencies: 2.6, 6.1/6.2, 8.8, 0.1.
