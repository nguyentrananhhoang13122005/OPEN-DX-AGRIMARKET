- (technique by coach) started The Zero-API Constraint: Imagine we are completely cut off from the internet and external APIs. How does the chatbot still get real-time price data using only local open-source tools and offline mechanisms?
- (technique by coach) started The Human-in-the-Loop Crawler: Instead of code scraping data, how can we leverage the human users of the app to build the dataset naturally?
- (technique by coach) started The LLM Reversal: Instead of AI answering based on data, what if the AI's job is to extract data from raw text to feed the DB, and a simple non-AI system answers the user?
