### 🟡 MEDIUM — Nên sửa (không block merge nhưng tạo tech debt)

#### [M1] Sai chuẩn đặt tên file (Naming Convention)
- **File:** Các file mới trong src/application, src/domain, src/infrastructure
- **Vấn đề:** Theo rules-and-limits.md §5.2 và AGENTS.md, quy tắc đặt tên file/folder trong dự án phải là **English kebab-case**. Việc sử dụng PascalCase cho các file UseCase, Port và Adapter là vi phạm quy chuẩn chung.
- **Cách sửa:** 
  Đổi tên các file theo format kebab-case:
  - SubmitDiagnosisUseCase.ts -> submit-diagnosis.usecase.ts
  - DiseaseDetectionPort.ts -> disease-detection.port.ts
  - StoragePort.ts -> storage.port.ts
  - DiseaseApiAdapter.ts -> disease-api.adapter.ts
  - MinioStorageAdapter.ts -> minio-storage.adapter.ts
