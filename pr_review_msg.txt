### 🔴 HIGH — Phải sửa trước khi merge

#### [H1] Gọi External API (Open-Meteo) trực tiếp từ Next.js
- **File:** `apps/web/src/app/api/weather/forecast/route.ts` | **Line:** 44
- **Vấn đề:** Vi phạm Data Pipeline Rules (AGENTS.md §Background). Next.js code không được phép gọi trực tiếp các API như Open-Meteo/USDA. Trách nhiệm này thuộc về n8n background workers.
- **Code lỗi:**
  ```typescript
  const forecast = await fetchOpenMeteoForecast(defaultLat, defaultLng, days)
  ```
- **Cách sửa:** Xóa logic fetch Open-Meteo khỏi route. Cập nhật dữ liệu thông qua n8n và cho Next.js đọc từ bảng `weather_cache`.

#### [H2] Ghi dữ liệu vào `weather_cache` từ Next.js
- **File:** `apps/web/src/app/api/weather/forecast/route.ts` | **Line:** 105
- **Vấn đề:** Vi phạm Data Pipeline Rules (AGENTS.md §Background). Không có route Next.js nào được phép WRITE vào bảng `weather_cache`.
- **Code lỗi:**
  ```typescript
  await prisma.weatherCache.upsert({ ... })
  ```
- **Cách sửa:** Xóa logic ghi DB. `weather_cache` chỉ được phép READ từ phía Next.js.

#### [H3] Route Handler chứa Business Logic & Gọi Prisma trực tiếp
- **File:** `apps/web/src/app/api/weather/forecast/route.ts` | **Line:** 24
- **Vấn đề:** Vi phạm Route Handler Pattern (AGENTS.md §Architecture). Route handler không được chứa business logic (`prisma.parcel.findMany`) mà phải delegate cho UseCase (Zod -> Adapter -> UseCase).
- **Code lỗi:**
  ```typescript
  const parcels = await prisma.parcel.findMany({ ... })
  ```
- **Cách sửa:** Chuyển logic truy vấn `weatherCache` (chỉ đọc) vào một `GetWeatherForecastUseCase` và gọi UseCase từ route.

#### [H4] Domain/Application Layer gọi Prisma trực tiếp
- **File:** `apps/web/src/application/chatbot/ChatbotUseCase.ts` | **Line:** 185
- **Vấn đề:** Vi phạm Dependency Rule của Hexagonal Architecture (AGENTS.md §Architecture). `ChatbotUseCase` nhận dependency trực tiếp qua việc import `prisma` thay vì qua Constructor Injection với interface Port.
- **Code lỗi:**
  ```typescript
  const records = await prisma.chatHistory.findMany({ ... })
  ```
- **Cách sửa:** Khai báo `ChatHistoryPort` (hoặc tương tự), inject vào `ChatbotUseCase` constructor, và viết PrismaAdapter implement port đó.
